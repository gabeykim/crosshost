# CROSSHOST — Paper Logic (Gate 12)

## The argument, in three sentences

Host specificity in bacterial regulatory activity resides substantially in cellular context (membrane, supercoiling, resource competition, growth physiology) rather than in the transcriptional machinery itself. Cell-free lysates retain the machinery but lose the context, and cross-host differences largely disappear as a result — 0.623–0.911 across all 45 species pairs in cell-free, versus 0.258 in vivo for the same *E. coli*–*B. subtilis* pair — a finding this project computed by comparing an independent cell-free dataset (DRAFTS) against its own in-vivo data, not a comparison DRAFTS's own authors made (confirmed directly against the primary source, `out/results/gate12_drafts_verification.md`). This predicts that host-descriptor features built from static composition — genome-encoded machinery annotations, and, on inspection, this project's own "physiology" vector too, since it is a coarse reference-proteome abundance proxy rather than a measurement of dynamic physiological state — should carry no signal, and across three conditioning mechanisms, an arbitrary host identity tag, and a pre-registered test, they do not.

## Accepted, with one clarification carried into the restructure

The logic inverts the paper correctly: the negative modeling results stop being the headline and become the confirmed prediction of a stated hypothesis, motivated by an independent dataset rather than accepted at face value. This is the right structure for what the evidence actually supports.

**The clarification:** the third sentence above extends "genome-derived host features... carry no signal" to *both* host-feature vectors this project built, not only the 37-D genomic one. This project's own 6-D "physiology" vector (ribosomal protein fraction, RNAP core fraction, sigma-factor fraction, chaperone fraction, EF-Tu/EF-G fraction, growth rate) was named and motivated by the Bernstein-lab physiology hypothesis, but on its own terms it is a **static, reference-database-derived composition proxy** — not a measurement of the dynamic physiological state (membrane potential, supercoiling, real-time resource competition, growth-phase transitions) the mechanistic hypothesis in sentence one is actually about. This distinction already exists in the current manuscript (Methods 2.2, Discussion's Bernstein-lab section) but needs to be visible at the point in §3.4 where the "prediction borne out" argument is made — otherwise a sharp reader reasonably asks "you tested a physiology vector and it also failed; doesn't that contradict the context hypothesis?" The answer is no, but only if the restructure states plainly that this project's physiology proxy is composition, not context, and was never positioned as a test of Bernstein-lab-style direct physiological measurement (the manuscript's existing scoping note on this is preserved, not weakened, by the restructure).

Nothing else in the proposed logic requires adjustment. Proceeding to Task 2.
