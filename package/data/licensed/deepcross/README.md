# DeepCROSS data quarantine — currently empty

The project charter anticipated a possible need to incorporate DeepCROSS-derived
data (Wang lab, Tsinghua; MIT license, academic use only — commercial use
requires contacting the DeepCROSS authors) and pre-provisioned this directory
for that purpose.

**No DeepCROSS data was ever incorporated into the CROSSHOST benchmark or any
of its baselines.** This directory exists so that if a future contributor adds
DeepCROSS-derived data, the licensing-quarantine pattern (separate directory,
separate LICENSE file, never merged into `data/core/`) is already in place and
does not need to be invented under time pressure. See `README.md` at the
package root for the full licensing-quarantine table.
